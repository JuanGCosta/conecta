CONECTA V12 - PRONTO PARA GITHUB

Este pacote já contém firebase-config.js com as configurações públicas do projeto conecta-f6ac1.
Substitua os arquivos do seu repositório pelos arquivos DE DENTRO da pasta conecta-v12.
Mantenha a pasta oculta .git de seu repositório.

CMD:
git add .
git commit -m "Conecta V12 - Melhorias"
git push origin main

IMPORTANTE: GitHub Pages atualiza apenas os arquivos do site.
O arquivo firestore.rules da V12 também precisa ser publicado separadamente em Firebase Console > Firestore > Regras, caso contrário avaliações e campos novos podem ter erro de permissão.

Os testes entre contas reais ainda devem ser realizados depois da publicação.
