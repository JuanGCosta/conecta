CONECTA V13 – CORREÇÕES

O pacote já contém a configuração pública do Firebase do seu projeto conecta-f6ac1.

CORREÇÕES
1. Chat: removida a leitura indevida de chats ainda inexistentes antes da primeira mensagem. Mantida verificação de autenticação e regras de acesso.
2. WhatsApp: link agora abre com a mensagem pré-preenchida "Olá! Vim pelo Conecta e gostaria de saber mais sobre seus serviços.".
3. Avaliações: corrigido o loop de renderização que afetava o clique e o desempenho. Incluído botão "Avaliar profissional" em perfis reais.
4. Pedidos: fotos processadas sequencialmente e comprimidas para reduzir lentidão, com indicação de progresso e tratamento de erro de armazenamento.
5. Portfólio: modal de adicionar trabalho com rolagem interna até o botão de salvar, inclusive no celular.

PARA PUBLICAR
Extraia o ZIP. Copie os arquivos de dentro de conecta-v13 para a pasta do seu repositório Git, substituindo os antigos. Preserve a pasta .git.
Execute no CMD:
  git add .
  git commit -m "Conecta V13 - Corrigir chat avaliacoes e formularios"
  git push origin main
Aguarde a publicação no GitHub Pages e atualize o navegador com Ctrl+Shift+R.

IMPORTANTE
- O arquivo firestore.rules é igual às regras preparadas para a V12. Se você já publicou essas regras no Firebase, não precisa republicá-las apenas por causa desta versão.
- As avaliações e mensagens reais precisam ser testadas no projeto Firebase entre duas contas verificadas; testes locais não substituem o Firestore real.
- Pedidos e fotos de portfólio permanecem salvos apenas no navegador, e não sincronizam entre dispositivos.
